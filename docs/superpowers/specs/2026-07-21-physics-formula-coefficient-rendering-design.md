# 物理公式系数变量字体一致性修复

## 问题

网页会把纯文本 `u>2f` 识别成 KaTeX 公式 `$u>2$` 加普通正文 `f`，导致同一个公式里的 `f` 使用两种字体。`f<u<2f` 也有相同问题。

## 方案

扩展纯文本公式识别规则中的表达式项，使比较符或等号后的 `2f`、`3x` 等“数字系数+单个变量”被整体识别。保持现有 LaTeX 分隔符、分数、物理单位和普通英文保护逻辑不变。

预期归一化结果：

- `u>2f` -> `$u>2f$`
- `f<u<2f` -> `$f<u<2f$`
- `u<f` -> `$u<f$`

## 验证

先添加覆盖上述三个表达式的失败测试，再实施最小正则修复。随后运行公式渲染测试、完整测试套件和 Python 编译检查，并确认只有设计、测试和公式识别代码发生变化。
