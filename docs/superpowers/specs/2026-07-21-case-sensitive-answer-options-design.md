# 答案与选项大小写敏感设计

## 目标

支持用 `DB`、`db` 等大小写变体作为正确答案 `dB` 的有效干扰项，帮助学生准确记忆单位和符号的大小写。

## 规则

所有知识填空和快速练习选项先清理首尾空格，并把连续空白压缩为单个空格；清理后的文本使用大小写敏感的精确比较。

- `dB`、`DB`、`db` 视为三个不同选项。
- `dB`、` dB `、`dB  ` 仍视为同一个选项。
- 正确判定继续使用精确文本比较，因此选择 `DB` 或 `db` 不会被判为 `dB` 正确。

## 影响范围

- 成品 DOCX 中干扰项的解析与去重。
- 知识填空和快速练习的上传数据校验。
- 知识填空词库构建时的答案排除与干扰项去重。
- 前端答题判定保持现状，因为知识填空和快速练习已经使用严格字符串比较。

## 方案比较

1. 全局使用清理后的大小写敏感比较：规则一致，适用于单位、变量、缩写和英文术语，采用此方案。
2. 只对白名单单位特殊处理：需要维护单位列表，容易漏掉新符号。
3. 只修改知识填空：会使快速练习仍拒绝相同的教学设计，行为不一致。

## 验证

添加回归测试，证明解析器保留 `DB` 和 `db`，校验器允许它们作为 `dB` 的干扰项，词库同时展示三个写法，并继续拒绝仅空格不同的真正重复项。最后运行完整测试与编译检查。
